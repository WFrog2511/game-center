# pnpm
## Status
パッケージマネージャとして使用する

## Context
npm より pnpm の方がインストールにかかる時間が短い。
[🔗参考リンク](https://zenn.dev/minedia/articles/2023-08-30-pnpm)

また、複数プロジェクトを同一リポジトリ内に立ち上げた場合、pnpmの優位性は更に高まる。
pnpmはパッケージをユーザディレクトリ内にインストールし、各プロジェクトにはショートカットのみを保存する。
一方、npmは各プロジェクトにもパッケージをインストールする。したがってストレージを圧迫し、更にインストール時間が長くなる。
