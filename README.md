# Game-Center

Game-Centerは、様々なゲームをホストするウェブプラットフォームで、最初のゲームとして2D協力シューティングゲームを提供します。

- [インストール](#インストール)
- [使い方](#使い方)


## 紹介

Game-Centerは、様々な種類のゲームを一元的に提供することを目的としています。初回リリースとして、プレイヤーが協力して敵と戦う2D協力シューティングゲームを提供します。

## 機能予定

- **2D協力シューティングゲーム**: 仲間と協力して迫りくる敵を倒すというシンプルなゲーム性。
- **多様な役職**: プレイヤーは個性豊かな役職を選択可能。
- **多彩な敵**: プレイヤーと同様に敵も多彩で、クリアには協力が必要不可欠。
- **マルチプラットフォーム**: PCのみならずスマホでもブラウザ経由でプレイ可能。

## インストール

プロジェクトのセットアップを行うには、以下の手順に従ってください：

1. リポジトリをクローンします：
    ```bash
    git clone https://github.com/WFrog2511/game-center.git
    cd game-center
    ```

2. 開発サーバーを起動します：
    ```bash
    docker-compose up --build
    ```

3. ブラウザで `http://localhost:3000` にアクセスします。

## 使い方

プロジェクトのセットアップが完了したら、ゲームをプレイできます。ゲームリストに移動し、プレイしたいゲームを選択してください。
